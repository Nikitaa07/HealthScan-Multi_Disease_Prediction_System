# HealthScan-Multi_Disease_Prediction_System
HealthScan is a simple web app that gives a quick idea of your risk for
three common health problems: heart disease, diabetes and liver disease.

You fill in a short form and get a risk level and a risk score in a few
seconds. It is built with Python, Streamlit and machine learning models.

Note: This is an educational project. The results are only a guide, not a
medical diagnosis, and do not replace a doctor's advice.
